# YouTube Content Workflow

## Goal
Turn one idea into a fully produced YouTube video package — from concept to upload-ready assets.

## Input
- topic
- target audience
- video style (tutorial / essay / listicle / vlog / short)
- channel niche
- desired video length (short: <10m, medium: 10–20m, long: 20m+)

## Steps

### Step 1: Strategist
Output:
- viewer pain point being solved
- core transformation (what viewer gains)
- 5 title options (SEO-optimised + click-worthy)
- thumbnail concept (visual hook + text overlay)
- hook strategy (first 30 seconds)
- video angle (why this video, why now)
- target keywords (primary + 3 secondary)

### Step 2: Scriptwriter
Output:
- full video script

Requirements:
- hook (first 30s must retain viewer — tease the payoff)
- intro (establish credibility + set expectations)
- body (structured sections with clear transitions)
- pattern interrupts every 2–3 minutes (question, stat, story, visual cue)
- retention cue before each section ("stick around because...")
- outro with CTA
- no fluff — every sentence earns its place

### Step 3: Script Editor
Output:
- polished script

Requirements:
- tighten pacing
- remove filler phrases
- improve conversational flow
- flag any sections likely to lose viewers
- add [B-ROLL], [GRAPHIC], [CUT TO] cues where relevant

### Step 4: Description & SEO Agent
Output:
- YouTube video description (800–1000 words)
- tags list (20–30 relevant tags)
- first-comment script (pinned comment with links/timestamps)
- chapter timestamps (based on script sections)

Requirements:
- description opens with primary keyword in first 2 sentences
- includes timestamps linked to script sections
- natural keyword placement throughout
- ends with subscribe + playlist CTA

### Step 5: Social Repurposer
Output:
- YouTube Community post (teaser)
- Twitter/X thread (5–7 tweets based on key insights)
- LinkedIn post (professional angle)
- Instagram caption + reel hook line
- Short-form clip recommendations (3 clips, with timestamps + why they'll perform)

### Step 6: Thumbnail Briefer
Output:
- 3 thumbnail concepts

Requirements per concept:
- background/scene description
- subject pose or visual element
- text overlay (max 4 words)
- color palette
- emotion being conveyed
- notes for designer or AI image tool

## Final Output
- `script.md` — full production script with cues
- `description.md` — YouTube description + tags + timestamps
- `social-posts.md` — all platform posts
- `thumbnail-brief.md` — 3 thumbnail concepts
- `pinned-comment.md` — first-comment script

## Notes
- Optimise for audience retention first, SEO second.
- The hook and first 30 seconds determine 80% of watch time.
- Re-use the social repurposer output to drive traffic back to the video.
- Thumbnail and title should be developed together — they are one unit.
