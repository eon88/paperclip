# CTA Options — Why Every Man Needs a Code

---

## CTA 1 — Newsletter Sign-Up

**The line:**
One piece a week on building the kind of character that holds under pressure. Subscribe below.

**Placement:** End of article

**Goal:** Newsletter sign-up

**Tone note:** "Character that holds under pressure" speaks directly to the article's core argument — that a code is what determines behavior when circumstances are difficult. Simple and on-brand.

## CTA 2 — Code Writing Exercise

**The line:**
Do this now: write your first draft. Three to five specific commitments — not values, commitments. Each one specific enough that you'd know immediately if you violated it. Don't make them aspirational. Make them honest. That's your starting point.

**Placement:** End of article, closing challenge

**Goal:** Immediate action / journaling exercise

**Tone note:** "Do this now" creates urgency. "Not values, commitments" reinforces the key distinction from the article. "Don't make them aspirational. Make them honest." is an important instruction that prevents the exercise from becoming performance — it should reflect where the man actually is, not who he wants to appear to be. No link — just the exercise.

---

## CTA 3 — Character Development Program or Cohort

**The line:**
The code is the foundation. Building it, testing it, and living by it across a sustained period is the work. If you want that done in community with other men who are taking it seriously, that's what this is for.

**Placement:** Mid-article, after explaining what makes a code real (specific, tested, yours)

**Goal:** Community, cohort, or program awareness

**Tone note:** "The code is the foundation" positions the article's subject as the beginning of a larger process. "Testing it and living by it" is what converts a written code into a real code — and that process is harder alone. The community framing (men taking it seriously) builds on the brotherhood need that shows up repeatedly across the content.
